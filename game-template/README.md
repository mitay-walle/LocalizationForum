# Шаблон репозитория игры

Один репозиторий на игру, языки — в папках. Строки переводятся на форуме, сюда бот коммитит утверждённый перевод в родном формате игры.

```
game.json            ← slug, название, форматы по расширениям, языки
source/              ← оригинал игры (как лежит в игре)
ru/  uk/ …           ← перевод; файлы строк пишет бот, остальное (LanguageInfo.xml, WordInfo/…) — обычными PR
rules/ru.json        ← правила проверки вариантов для языка
scripts/forum.mjs    ← связь с форумом (без зависимостей)
github-workflows/    ← import / sync / release — при создании репо игры переместить в .github/workflows/
```

## Настройка

1. Создать репозиторий из этой папки, перенести `github-workflows/*.yml` в `.github/workflows/` и заполнить `game.json`:
   - `slug` — латиница, цифры, дефис (`rimworld`, `my-game`);
   - `format_map` — формат по расширению файла: `{".xml": "rimworld", ".json": "json-nested", ".png": "-"}` (`-` — не переводить, копировать как есть). Необязательно: расширения, которых нет в карте, форум подберёт сам при импорте; карту можно поменять и в настройках игры на форуме. Старое поле `format` — формат по умолчанию;
   - `languages` — папки языков (`["ru"]`).
2. Положить оригинальные файлы в `source/`. Для RimWorld — папки вида `Core/Keyed`, `Core/DefInjected`, `Royalty/…` (английские файлы или сгенерированные игрой с `TODO` и комментариями `EN:`).
3. Settings → Secrets and variables → Actions:
   - Variables: `FORUM_API_URL` = адрес форума на Vercel;
   - Secrets: `FORUM_SYNC_TOKEN` = `SYNC_TOKEN` форума.
4. Push — workflow **Import source** загрузит строки.

Уже есть готовый перевод? Положите его в папку языка и запустите **Import source** вручную, указав язык: строки станут утверждёнными (существующие не перезаписываются без галочки overwrite).

## Как это работает

| Workflow | Когда | Что делает |
|---|---|---|
| **Import source** | push в `source/`, `rules/`, `game.json` | новые строки добавляются, изменённые помечают перевод «устаревшим», пропавшие скрываются |
| **Sync translations** | через ~10 минут после утверждений на форуме, раз в сутки, вручную | выгружает утверждённые переводы в папки языков и коммитит |
| **Release translation** | вручную: язык + версия | свежая синхронизация → `ru-1.6.0` в Releases с zip папки языка и титрами |

Версии игры — ветками, как у RimWorld-ru: `master` — актуальная, `1.5`, `1.4` — старые. Релиз собирается из той ветки, где он запущен.
